# Kalorické tabulky 📊🍎

## Hlavní funkce  
1. **Záznam denního příjmu potravy**  
   - Možnost zapisovat jednotlivé potraviny a jejich nutriční hodnoty:  
     - **Bílkoviny**  
     - **Sacharidy**  
     - **Tuky**  
   - Automatický výpočet celkového denního příjmu kalorií a makroživin.  

2. **Osobní cíle** 🎯  
   - Výpočet denního kalorického příjmu na základě osobních údajů:  
     - **Výška**  
     - **Váha**  
     - **Věk**  
     - **Cíle** (např. hubnutí, udržení váhy, nabírání svalové hmoty).  

3. **Vyhledávání a skenování potravin** 🔍📷  
   - Možnost:  
     - Naskenovat čárový kód potraviny a získat její nutriční hodnoty.  
     - Vyhledat potravinu v databázi a přidat ji do kalorických tabulek.  
   - Funkce automaticky aktualizuje denní přehled příjmu.  

4. **Hlavní stránka aplikace** 🏠  
   - Přehledný **dashboard** zobrazující:  
     - Celkový příjem kalorií.  
     - Splněné aktivity.  
     - Hmotnost.  
   - Podrobnosti o přijatých hodnotách:  
     - **Celkové kalorie**  
     - **Bílkoviny**, **sacharidy**, **tuky**  
     - Denní cíle pro jednotlivé složky.  

---

## Konkurence  
Podobné aplikace dostupné na trhu:  
- **MyFitnessPal**  
- **Yazio**  
- **Cronometer**  

---

## Technologie  
- **Frontend**: Flutter (podpora pro Android i iOS).  
- **Backend**: MySQL (databáze).  
- **API**: REST API pro komunikaci mezi frontendem a databází.  
- **Skenování čárových kódů**: Integrace knihovny pro zpracování čárových kódů (např. `barcode_scan2`).

---

## Plánované vylepšení 🚀  
1. Přidání možnosti sledování aktivit (např. počet kroků, cvičení).  
2. Možnost synchronizace s nositelnými zařízeními (např. Fitbit, Apple Watch).  
3. Statistiky a grafy pro dlouhodobé sledování pokroku.
